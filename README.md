# GlassBoost • Luxury Game Lag Booster & FPS Monitor
### معزز الألعاب الخارق وإزالة اللاغ بهوية زجاجية فاخرة

تطبيق متطور لهواتف أندرويد مصمم بأسلوب **Glassmorphism** المعماري الفاخر، لتسريع الألعاب، وتتبع أداء الهاتف ومعدل الإطارات (FPS)، وزمن الاستجابة (Ping)، واستهلاك المعالج والرسومات (CPU & GPU)، مع ميزة الشاشة العائمة وإغلاق العمليات الثقيلة تلقائياً.

---

## 🚀 كيفية بناء وتحميل الـ APK عبر GitHub (GitHub Actions)

تم إعداد ملف سير العمل الآلي بالكامل داخل المسار:
`.github/workflows/build-apk.yml`

### خطوات البناء والتحميل:
1. **رفع المشروع إلى GitHub (Push to GitHub):**
   - من شريط أدوات AI Studio في الأعلى، اضغط على زر الإعدادات أو أيقونة المشاركة/GitHub، ثم اختر **Push to GitHub** أو قم بتصدير المشروع (Export ZIP) ورفعه إلى مستودعك الخاص.
2. **بدء البناء الآلي (Automated CI/CD Build):**
   - بمجرد رفع الكود، سيبدأ GitHub Actions تلقائياً بتنفيذ سير العمل `Build GlassBoost Android APK`.
   - يمكنك أيضاً تشغيل البناء يدوياً في أي وقت عبر الدخول إلى تبويب **Actions** في صفحة المستودع على GitHub، ثم اختيار `Build GlassBoost Android APK` والضغط على **Run workflow**.
3. **تحميل ملف الـ APK:**
   - بعد اكتمال البناء (تظهر علامة صح خضراء ✅):
   - اضغط على تفاصيل تشغيل الـ Workflow.
   - انزل إلى قسم **Artifacts** في الأسفل.
   - اضغط على **`GlassBoost-GameBooster-APK`** لتحميل الملف وتثبيته مباشرة على جهاز أندرويد الخاص بك!

## 🛠️ البناء المحلي (Local Build)

إذا كنت تفضل بناء التطبيق محلياً على جهازك:
```bash
chmod +x gradlew
./gradlew :app:assembleDebug
```
الملف الناتج سيكون في المسار:
`app/build/outputs/apk/debug/app-debug.apk`

## ✨ المميزات الرئيسية
- **تتبع ورسم بياني تفاعلي (Interactive Performance Charts):** عرض وتتبع لحظي لمعدل الإطارات (FPS)، زمن الاستجابة (Ping ms)، واستهلاك المعالج والرسومات (CPU% & GPU%).
- **المعزز التلقائي الذكي (Auto-Boost Engine):** كشف العمليات وتطبيقات الخلفية الثقيلة، إنهاؤها، وتحرير مئات الميجابايت من الرام (RAM).
- **مُثبّت الشبكة (Network Optimizer):** فحص واختيار خوادم الألعاب الإقليمية (الرياض، دبي، جدة، فرانكفورت) وضبط مسارات الـ DNS لتقليل التذبذب (Jitter) واللاغ.
- **الشاشة العائمة (Floating HUD Overlay):** تتبع حي للأداء فوق أي لعبة دون مغادرتها.
- **مكتبة الألعاب (Turbo Game Launcher):** تخصيص دقة العرض ومعدل الإطارات لكل لعبة وإطلاقها بضغطة واحدة.
