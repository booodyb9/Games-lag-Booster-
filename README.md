# GlassBoost — Android game preparation and diagnostics

تطبيق Kotlin / Jetpack Compose لتحضير جلسة اللعب، وتنظيف كاش التطبيق، ومراقبة RAM والحرارة وفحص اتصال TCP.

## ما يعمل فعليًا
- حذف ملفات كاش GlassBoost فقط مع عدّ البايتات المحذوفة والإبلاغ عن تعذّر الحذف.
- قياس RAM المتاح قبل/بعد العملية. التغيّر المرصود قد ينتج عن نشاط النظام، ولا يثبت تحرير RAM لتطبيق آخر.
- وضع ألعاب باستخدام Android Do Not Disturb بعد منح إذن واضح. يحترم استثناءات الأولوية في الهاتف. أوقفه من شاشة وضع الألعاب بعد اللعب.
- فحص TCP متعدد المحاولات لوجهات عامة، وعرض التذبذب دون قصّ القيم، ونسبة فشل الاتصالات.
- الحفاظ على الوجهات الإقليمية والعامة واختيار أسرع وجهة اختبار ناجحة. الاختيار لا يغيّر مسار بيانات اللعبة.
- حفظ ملفات تفضيلات FPS والدقة لكل لعبة. طبّق هذه القيم يدويًا من إعدادات اللعبة نفسها.
- إعدادات تحضير محفوظة تتحكم فعليًا في حذف الكاش وفحص الشبكة والتحضير التلقائي وملخص النتائج.
- HUD اختياري بعد إذن الظهور فوق التطبيقات. تعديل الشفافية لا يشغّل الخدمة، وزر الإغلاق يزامن حالتها.
- إحصاءات جلسات تستبعد القياسات غير المتاحة، وتبدأ بسجل فارغ دون جلسات عشوائية.

## حدود القدرات
لا يتوفر Root أو Shizuku أو خادم VPN في هذا المشروع. Android لا يسمح لهذا التطبيق بفرض FPS/دقة لعبة أخرى أو إنهاء تطبيقاتها على Android 14+. لذلك يظهر FPS اللعبة كغير متاح، ويمكن فتح معلومات التطبيقات لإدارتها يدويًا.
تهيئة DNS ومقبس TCP تخص هذا التطبيق فقط؛ ليست VPN ولا تخفض Ping اللعبة بالضرورة. حرارة البطارية ليست حرارة المعالج. التسجيل يجمع قياسات النظام ما دام التطبيق يعمل؛ لا يستخرج بيانات من محرك اللعبة.

## الصلاحيات
- Internet: اتصالات الاختبار العامة.
- Overlay + foreground service: الشاشة العائمة اختيارية، مع إشعار الخدمة المطلوب من Android.
- Notification policy access: اختياري لتقليل المقاطعات أثناء اللعب؛ يمكن إلغاؤه من إعدادات الهاتف.
- Package visibility: اكتشاف الألعاب والتطبيقات القابلة للتشغيل.

## البناء والاختبارات
JDK 17، Gradle wrapper 9.3.1، AGP 9.1.1، compile SDK 36.1، min SDK 24.
البناء المحلي يحتاج ملف debug.keystore المتوافق مع إعدادات المشروع، أو استخدم GitHub Actions الذي يعدّه تلقائيًا.

```bash
bash gradlew :app:testDebugUnitTest :app:assembleDebug
```

الناتج: `app/build/outputs/apk/debug/app-debug.apk`.
Workflow: **Build GlassBoost Android APK**. Artifact: **GlassBoost-GameBooster-APK**.
فشل الاختبارات يوقف الـworkflow. هذه نسخة Debug وليست إصدار متجر، ولم تُقَس زيادة FPS أو انخفاض Ping داخل لعبة على جهاز فعلي.
